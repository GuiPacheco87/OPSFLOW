# Roadmap

## V1 — MVP funcional

- [x] autenticação JWT e organizações;
- [x] RBAC simples;
- [x] workflows e etapas;
- [x] execuções, tarefas e decisões;
- [x] SLA e auditoria;
- [x] dashboard operacional;
- [x] Docker Compose, testes e CI;
- [x] demonstração pública gratuita.

## V1.1 — Produto demonstrável

- [ ] edição visual e reordenação de etapas;
- [ ] templates de onboarding, acessos e reembolso;
- [ ] busca, filtros e paginação;
- [ ] comentários e anexos;
- [ ] notificações por e-mail e webhook;
- [ ] recuperação e alteração de senha.

## V2 — Integrações e escala

- [ ] OAuth Microsoft e Google;
- [ ] Slack, Microsoft Teams e webhooks assinados;
- [ ] formulários configuráveis por workflow;
- [ ] delegação e substituição temporária de aprovadores;
- [ ] versionamento de workflows em uso;
- [ ] rate limiting e observabilidade completa.

## V3 — Dados e inteligência operacional

- [ ] eventos de domínio para um data lake;
- [ ] camadas Bronze, Silver e Gold;
- [ ] métricas de tempo de ciclo e cumprimento de SLA;
- [ ] detecção de gargalos e previsão de atrasos;
- [ ] dashboards executivos e exportação para BI.
